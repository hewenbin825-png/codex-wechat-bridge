# 按聊天开启微信提醒

微信模式只绑定当前聊天 ID。默认 `native`：普通问题使用 Codex 原始选择卡，不创建桥接问题，不发微信问询或完成通知。安装 skill、服务恢复、其他聊天开启、分叉聊天、Dot 新建工作都不自动启用。旧版“全局默认微信”规则不再适用。

不注册 Windows 开机或登录自启项。仅在启动 Codex 时由 MCP / SessionStart 在后台启动微信桥接和已配置的艾莉丝隧道，不弹终端窗口。已连接不等于所有聊天开启通知；无需为微信连接或艾莉丝聊天打开工作任务通知。

用户在本聊天明确说“微信通知我”“问题发微信”等要求时，调用 `mcp__wechat_bridge__set_chat_mode`，`mode=wechat`，无需重复确认。用户要求恢复电脑问题卡或关闭本聊天微信时，设 `mode=native`。工具仅定位实际调用聊天，不接受任意目标；设置重启后保持。新工具未加载时说明需要重载连接，不调用旧版会弹原生卡的 ask_user。

## 微信模式普通问答

1. 调用 `ask_user`，每次一题，提供稳定 `id`、`question` 和可选 `options`。立即返回的 `pending` 只表示创建问题，不是答案；不创建原生卡。
2. 将返回的 `local_question_markdown` 醒目显示在当前聊天中，保留题号和选项。用粗体标题和引用块，不做自绘弹窗，不调用 `request_user_input` / `request_user_input_async`。提醒走艾莉丝已连接的微信桥接直接发送，不等待 Dot 推理；入队不等于手机收到。
3. 微信可答选项或自由文字，真实答案自动投递同一原聊天；无需 computer-use、回填或关闭卡片。电脑直接发送的真实答案，用 `answer_from_chat(request_id, question_id, text)` 记录，只传用户实际回答，不代选或把别题内容当答案。
4. 先收到的有效答案生效，两端竞答以返回的已记录答案为准，不覆盖。必要答案未收到前不做依赖工作，可继续独立工作或以醒目问题结束等待；Stop 不把待答误报为完成。
5. 用户取消或问题不再需要时用 `cancel_question`。取消、错误、过期、沉默都不是答案。电脑新消息、MCP 退出、工具结束不自动取消文字问题；问题默认 24 小时有效，重启后保留，`/clear` 可显式取消。

仅微信模式不用问题卡。未开启微信的其他聊天照常使用 Codex 原始卡，不因本聊天设置改变。旧原生回填授权不触发新问题的卡片或电脑控制。

## 号码和补充

- 当前只有一题：微信直接回 `1`、`2` 或自由文字。多题用 `1.1`、`2.2`、`2.这样改`，点号前是稳定题号，答完不重排。
- 已答题可发 `5.补充内容`，只投递第 5 题原聊天；重复纯数字不是补充，不新建任务。原聊天关闭微信后，在电脑补充。
- `/clear` 同时清空题号和任务号（包括艾莉丝任务），取消待答和尚未投递的编号提示词。下一题和下一个新任务从 1 开始，旧入口失效；保留聊天、历史、完成去重、运行中的工作以及各聊天模式。
- 完成摘要显示固定任务号；`/1 下一步要求` 只回任务 1 原聊天。仅一个可续办主任务时可用 `/继续任务`；多个任务必须指定，不能默认最新。用 `/任务` 查看。投递未确认不声称开始，补充与续办均不是执行许可。

## 艾莉丝对话与提醒

`/艾莉丝 对话` 开启连续聊天，`/艾莉丝 文字` 直接交谈，无待答题时普通文字可续聊。待答题、题号补充、任务号命令优先按原路由处理。`/艾莉丝 退出对话` 退出。

只有 `/艾莉丝 创建任务 具体要求` 或 `/新任务 具体要求` 才创建独立 Codex 工作；`/艾莉丝 继续任务 任务号 下一步要求` 只续办明确登记的聊天。`intent=conversation` 只直接回复，不创建工作或占任务号。具体执行留在独立工作上下文，新工作不自动开启微信模式。

问题和完成提醒由桥接确定性发送，标识“艾莉丝提醒”；这是已连接的微信出口，不代表 Dot 为每条提醒运行一轮。真实连续聊天仍由 Dot 处理，本机不能保证云端排队速度，不声称未实测的提速。

## 完成与故障

仅已开启微信的本机主聊天，完成时由 Stop 和桌面检测按聊天、轮次去重发摘要；子智能体不通知、不分配任务号。不要额外发送重复通知；未开启聊天不扫描完成内容、不发送摘要。

微信不可用时，已开启聊天仍用醒目文字提问、电脑直接回答，不恢复成问题卡；默认 native 聊天仍用原始卡。新入站微信可更新会话上下文，不必每轮发“激活”；明确失效才要求恢复。skill 存在或消息入队不能代替真实连接、手机实收验收。

执行权限审批、登录、安全设置始终走 Codex 原审批，不进入普通微信问答。模式开关不改变沙箱或权限。管理页只是额外入口。安装位于当前用户 `.codex/codex-wechat-bridge`，状态用 `get_status` 查询。
