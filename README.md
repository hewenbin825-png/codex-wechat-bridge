# Codex WeChat Bridge

把本机 Codex 的轮次结束摘要与普通问询接到个人微信。单题直接回复 `1`、`2` 或文字；多题回复 `1.1`、`2.2`、`2.这样改`。答案返回正在等待的原聊天。

当前版本：**0.1.2**。面向 **Windows + Node.js 24+ + Python 3.11+**，需要 Codex 提供 MCP 和 Hooks 支持，以及微信端的 ClawBot 扫码接入资格。

## 功能与作用

| 功能 | 用途 |
| --- | --- |
| 轮次结束摘要 | 离开电脑后，在微信了解本轮结果；摘要最多 180 字符 |
| 选项和自由文字回复 | 在手机选择方案、补充信息，让原任务继续 |
| 稳定题号 | 多题、多个聊天同时等待时区分答案，回答后不重排 |
| 固定主任务号 | 完成通知区分多个主任务，子智能体完成不通知、不占号 |
| 斜杠续办 | `/1 提示词` 投递到对应原聊天；真实桌面链路仍待验收 |
| 本机队列和状态保存 | 保存待答状态、处理重复与迟到消息、在重启后保留题号 |
| 原聊天回填 | 通过同一个 MCP 调用返回答案，无需另开聊天转述 |
| 配套 skill | 保留问答格式和故障回退约定 |
| 保留原通知链 | 完成摘要走独立 Stop 钩子，安装时保留原 notify 配置 |

## 回复示例

```text
【报告整理】
第1题：下一步怎么处理？
1. 先修正，再继续
2. 先整理问题
```

只有一题：直接回复 `1`、`2`，或者 `先把原因整理出来`。

多题同时等待时，每条消息回答一题：

| 回复 | 解析 |
| --- | --- |
| `1.1` | 第1题选第1项 |
| `2.2` | 第2题选第2项 |
| `2.这样改` | 第2题自定义回答“这样改” |
| `（2.这样改）` | 同上 |

题号以消息显示为准，在本机跨聊天持续分配，不重复使用，重启后保留。无需随机 Q 编号或“自定义：”前缀；旧格式继续兼容。

## 工作原理

```text
普通问题 → MCP ask_user 等待 → 本机桥接 → 个人微信
原任务继续 ← 同一调用返回答案 ← 按题号路由 ← 数字/文字回复

Codex 本轮结束 → Stop 钩子 → 本机队列 → 微信短摘要
```

微信使用腾讯公开仓库记录的 iLink 接口，本项目直接实现所需的消息链路，不需要额外运行一个负责转述答案的大模型。

## 安装

1. 在 PowerShell 中运行 `& .\Install.ps1`。安装器会备份配置，合并本桥接 MCP 与 Hooks，并配置当前用户登录启动。
2. 打开当前用户 `.codex/codex-wechat-bridge/open-manager.ps1`，通过本机 Edge 进入管理页。
3. 绑定微信并扫码确认，在微信 ClawBot 发送“激活”。
4. 在 Codex 中检查钩子审阅状态；需要时使用 CLI `/hooks` 审阅本项目钩子。重新加载已有聊天。

程序安装在当前用户 `.codex/codex-wechat-bridge`。本机管理服务仅监听 `127.0.0.1:17349`。

配套 skill 位于 [skills/wechat-task-qa/SKILL.md](skills/wechat-task-qa/SKILL.md)，可复制到当前用户 `.codex/skills/wechat-task-qa/SKILL.md`。安装器写入全局问答指引；skill 文件需单独复制。

## 常用操作

- 微信发送“待答”：查看仍在等待的问题和题号。
- 微信发送“状态”：检查连接。
- 微信发送“激活”：刷新平台要求的消息上下文。
- 管理页：暂停、恢复、重新绑定及发送连接测试。
- `Uninstall.ps1`：移除本程序配置与登录启动项，保留原通知、后续用户配置及默认保留的加密状态。

## 多个任务完成后继续

完成消息使用“任务 1｜聊天名称｜本轮结束”格式，附固定任务号。`/1 继续任务` 或 `/2 修改报告标题` 只向对应原主聊天提交下一步提示词。只有一个可续办任务时可发 `/继续任务` 或 `/先整理原因`；多个任务而未带号时返回列表，让用户明确选择。`/任务` 查看最近任务。

题号 `1.1` 与任务续办 `/1 提示词` 分开。普通文字只回答待答问题。续办由已安装的官方 Codex App Tools 服务投递，需桌面连接 `desktop_connector.ready=true`；未连接明确回报尚未提交，不自动猜测任务或重发不确定的投递。执行权限仍由 Codex 审批。

## 数据与覆盖范围

微信凭据通过当前 Windows 用户 DPAPI 加密保存；安装目录限制为当前用户和 SYSTEM 访问。问题、答案及投递元数据保存在本机 SQLite，不上传完整聊天历史。公开源码不包含真实微信令牌、控制令牌、配置备份或会话数据库。

普通问题使用 `mcp__wechat_bridge__ask_user`。工具失败、取消或过期时回到 Codex 询问，不自动代答。权限审批继续使用 Codex 原流程，普通微信文字不会自动创建新任务。

电脑需要开机联网。平台登录、上下文和推送额度受微信服务约束；发送结果不确定时不会盲目重发。模型直接用普通文字提出的问题、绕过 Hooks 的专用工具及远程主机尚未取得普遍覆盖证据。
